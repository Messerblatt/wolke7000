## FLITZA

![[shark_1_1.png]]

FLITZA ist das bekannteste, aber nicht das einzige Fahrzeug der Shark-Reihe. [[funky (dot) blend|Funky]] entwickelte mehrere verwandte Entwürfe für unterschiedliche Einsatzzwecke.

| Shark-Modell | Aufgabe               | Besonderheit                                           |
| ------------ | --------------------- | ------------------------------------------------------ |
| **Sprint**   | Rennboot              | Maximale Beschleunigung auf kurzen Strecken            |
| **Courier**  | Kurierfahrten         | Kleine Ladebox und Open-Wing-Empfangsfach              |
| **Rescue**   | Wasserrettung         | Seitliche Aufnahmevorrichtung für Verletzte            |
| **Bite**     | Abfangboot            | Verstärkter Bug und Schlepphaken                       |
| **FLITZA**   | persönlicher Prototyp | Unvernünftig schnell und offiziell „noch in Erprobung“ |

Die Baureihe wurde nie patentiert. Sämtliche Baupläne sind offen zugänglich, wobei die Version von FLITZA mehrere Module enthält, die von [[funky (dot) blend|funky]] als **„Benutzung auf eigene Dummheit“** gekennzeichnet wurden.
